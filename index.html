AutoSkip Privacy Policy

Last updated: October 8, 2026

AutoSkip is designed to automatically interact with supported Skip and Close controls using Android Accessibility Service.

1. About AutoSkip

AutoSkip is an Android application designed to help users automatically activate supported Skip buttons and Close/X controls that appear on the screen.

2. Accessibility Service

AutoSkip uses Android's Accessibility Service because this permission is required to detect visible interface elements and perform supported interactions on behalf of the user.

Accessibility access is a sensitive Android permission. Android may display additional security warnings or restrict access depending on how the application was installed.

Important:
Android may show messages such as "Controlled by restricted setting" or "App was denied access". These messages are Android security protections and do not by themselves mean that AutoSkip is a malicious or hacking application.

3. Information AutoSkip Does Not Request

AutoSkip does not request permissions for:

  • Contacts
  • Photos and videos
  • SMS messages
  • Device location
  • Microphone
  • Camera

4. Internet and VPN

AutoSkip does not use a VPN to control or redirect your internet connection.

5. Notifications

AutoSkip may request Android notification permission on supported Android versions. This permission is declared for compatibility, but AutoSkip does not use it to send advertising or promotional notifications.

6. Advertising

AutoSkip does not provide advertising inside its own application.

7. Data Collection

AutoSkip does not intentionally collect or sell personal information through its automatic skipping functionality.

8. Third-Party Applications

AutoSkip may interact with visible user-interface elements provided by other applications when Accessibility access is enabled. AutoSkip does not control the privacy practices or data handling of those third-party applications.

9. User Control

Accessibility access can be enabled or disabled by the user through Android Settings. Users should only enable Accessibility access for applications they trust.

10. Security

AutoSkip is designed to use Accessibility access only for its intended automatic Skip and Close functionality.

11. Changes to This Privacy Policy

This Privacy Policy may be updated if the functionality of AutoSkip changes. Any updated version will be published on this page.

12. Contact

For questions about AutoSkip or this Privacy Policy, please contact the AutoSkip developer through the official project repository.
